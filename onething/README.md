# 한 가지 (One Thing Finder)

방법론을 팔지 않는다. **맥락을 읽고 가설을 돌려준다.**

`index.html` 하나만 열면 동작한다. 빌드도, 서버도, 외부 의존성도 없다. 모든 입력은 브라우저 localStorage에만 남고 어디로도 전송되지 않는다.

---

## 왜 만들었나

자기계발 시장은 방법론으로 넘친다. 같은 책을 읽고 인생이 바뀐 사람과 아무것도 안 바뀐 사람이 갈린다.
성공한 사람은 **자기 인생이라는 서사 안에서 그 맥락에 맞는 방법을 썼기 때문에** 성공했다. 방법이 좋아서가 아니라.

그러니까 먼저 필요한 건 또 하나의 방법론이 아니라 **나라는 사람의 맥락**이다.
이 앱이 파는 건 답이 아니라 맥락 해상도다.

## 네 개 층으로 읽는다

| 층 | 무엇을 | 출처 |
|---|---|---|
| 서사 | 좋아하는 걸 묻지 않고 **실제로 있었던 일**을 묻는다 | 자기보고 대신 증거 |
| 강점 | SIGN 지표(성공·본능·성장·충전)로 재능을 추출 | 강점 혁명 |
| 이키가이 | 채워진 칸이 아니라 **비어 있는 칸**을 찾는다 | 이키가이 |
| 맥락 | 시간·노출·수익 시급성·본업 리스크로 거른다 | 이 앱의 차별점 |

그리고 원싱(게리 켈러)의 초점 질문을 사다리로 내려 **오늘 30분**에 닿게 한다.

## 설계 판단 세 가지

**1. 충전(N)에 가장 큰 가중치를 준다 (×1.5)**
과거의 성공(S)은 *기회가 있었느냐*에 오염되어 있다. 해볼 기회가 없었던 재능은 성공 기록을 남기지 못한다.
반면 "하고 나면 오히려 기운이 났는가"는 오염되지 않는다. 그래서 충전 > 본능(1.2) > 성장(1.1) > 성공(1.0).

**2. 맥락은 가산점이 아니라 감점이다**
노출·시간·수익 시급성·리스크는 요구치가 감당치를 넘는 만큼 직접 깎는다.
노출과 리스크(각 0.13/단계)가 가장 무겁고, 시간(0.07)이 가장 가볍다 — 시간은 늦게 갈 수라도 있지만 노출과 리스크는 벽이기 때문이다.

**3. 대표 강점은 평균에 묻히면 안 된다**
가중평균만 쓰면 "두루 무난한 길"이 1등이 된다. 그래서 그 길이 가장 크게 요구하는 강점이 사용자의 1순위 강점이면 +0.10, 2순위면 +0.05, 대표 연료가 일치하면 +0.06을 따로 얹는다.

최종 점수 = `0.45×강점적합 + 0.35×연료적합 + 0.20×빈칸기여 + 대표성보너스 − 맥락감점`

## 다른 진단 도구와 뭐가 다른가

- **정답이 아니라 가설을 준다.** 끝이 결과 페이지가 아니라 2주 실험 설계다. 검증되지 않은 가설은 값어치가 없다.
- **근거를 전부 공개한다.** 몇 점인지가 아니라 왜 그 점수인지, 어디서 감점됐는지를 다 보여준다. 사용자가 반박할 수 있어야 한다.
- **"당신에게는 독이 될 조언"을 짚는다.** 좋은 조언이어서 더 위험하다. 다른 맥락에서는 맞는 말이기 때문이다.
- **과정을 콘텐츠로 뽑아준다.** 찾은 다음에 기록하는 게 아니라, 찾는 과정을 기록한다. (프로세스 이코노미)

## 구조

```
onething/
└── index.html   # 전부 (구조 · 스타일 · 24개 경로 카탈로그 · 채점 엔진 · 결과 렌더)
```

`<script>` 블록 세 개로 나뉜다.
1. **DATA** — 강점 12테마, SIGN 가중치, 동기 6축, 이키가이 4칸, 맥락 6문항, **경로 24개**, 키워드 사전, 독이 될 조언 8룰
2. **STATE + ENGINE** — 입력 폼 생성, 점수 계산(`computeThemes` / `computeMotives` / `scorePaths` / `profile`)
3. **RENDER + NAV** — 결과 렌더, 초점 질문 사다리, 2주 실험, 콘텐츠 초안 생성

경로를 추가하려면 `PATHS`에 한 항목만 넣으면 된다.

```js
{id:"…", name:"…", one:"한 줄 설명",
 t:{강점키:가중치}, m:{동기키:가중치},
 need:{exp:0-3, time:0-3, lag:0-3, risk:0-3},   // 이 길이 요구하는 것
 fills:["이키가이 칸"],                          // 어느 빈칸을 채우는 길인가
 exp2w:"2주 실험", content:"콘텐츠로 뽑는 법"}
```

## 검증

- `node --check`로 문법 확인
- 정반대 맥락의 두 프로필(내향·저노출·장기 vs 외향·고노출·단기)을 넣었을 때 상위 경로가 완전히 갈리는지 확인
- Playwright로 전 단계 클릭 → 결과 렌더까지 콘솔 에러 0
