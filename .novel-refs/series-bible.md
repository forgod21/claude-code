# 세계관 7규칙

작품의 척추. 여기가 흔들리면 50화에서 무너진다.

**1. 중원에 화약이 없다.**
총도 화포도 폭약도 없다. 원거리 무기는 활. 가상 중원이므로 실제 왕조를 특정하지 않는다.

**2. 고수는 총알을 피하지 않는다. 격발 전에 움직인다.**
살기·조준선·근육의 예비동작을 읽는다.
- 근거리 정면 = 고수가 유리 (진우가 질 수 있음)
- 원거리·은폐·기습 = 진우 절대 우위
→ 진우의 전술은 필연적으로 **저격**. 아버지가 가르친 것과 일치.

**3. 진우는 기(氣)를 신호로 이해한다.**

| | 중원 무인 | 진우 |
|---|---|---|
| 인식 | 흐름 | **신호 (파장·주파수)** |
| 수련 | 경지 돌파 | 대역 확장, 출력 조정 |
| 특기 | 내공량·초식 | **지향성, 원거리 감지, 간섭** |

파생: 기탄(지향성 발사) / 원거리 기감(수신) / 상대의 기 운용 방해(간섭) / 후반 차원 간 교신.
**저격=거리, 통신=파장, 내공=진동. 전부 같은 문제.**

**4. 지구와 중원은 다른 차원이며 기의 법칙이 다르다.**
지구에서 내공을 운용하면 주화입마. 중원에서는 정상.
→ **진우는 지구로 돌아갈 수 없다.** 돌아가면 힘을 잃거나 죽는다.

**5. 봉인은 순수한 보호였다.**
아버지는 아들이 지구에서 주화입마에 걸리지 않도록 막아뒀다. 아들이 차원 이동할 거라곤 생각 못 했다.
전이 순간 기 환경이 바뀌며 **자연히** 풀린다. 인위적 장치 없음.

**6. 봉인 해제는 파워업이 아니라 위기다.**
20년치 내공이 쏟아지는데 몸이 못 버틴다. 외공이 하급이므로.
1부의 목표는 "강해지기"가 아니라 **"이 힘을 담을 몸을 만들기"**.

**7. 성장 지표 = 통제율.**

```
1부 초반  10%  한 번 쓰면 사흘 앓아눕는다
1부 중반  20%  하루 한 번
1부 후반  35%  연속 두 번
2부       60%  일상적으로
3부      100%  기탄
```

상태창을 대체한다. 매번 대가가 있어 남발 불가.

# 1부 적대 세력 (1~25화)

아버지 쪽 음모는 2부로 미룬다. 1부에는 독립적인 적이 필요하다.

```
아크 1 (1~6화)    녹림 말단          ← 첫 조우의 그들
아크 2 (7~14화)   녹림 본대 + 광산    ← 초석 확보가 곧 충돌
아크 3 (15~25화)  녹림이 고용한 궁사  ← 진짜 적수
배경              관(官)의 관심       ← 2부 압력
```

**광산**: 초석·유황·구리 산지를 녹림이 쥐고 있다. 재료를 구하는 게 곧 싸우는 것.

**몰락한 궁술 명가**: 한때 중원 제일이었으나 쇠락. 후예가 산적 밑에서 돈을 받고 일한다.

> 네 물건이 퍼지면, 내 삼십 년은 아무것도 아니게 된다.

| | 궁사 | 진우 |
|---|---|---|
| 세계관 | 10년을 쏴야 하나를 맞힌다 | **사흘이면 누구나 쏜다** |
| 가치 | 재능과 수련 | 기술과 보급 |
| 미래 | 없다 | 있다 |

**거울상 구조** — 둘 다 쓸모를 증명해야 하는 사람.
단순 악역이 아니라 **문명 교체의 비극**.

## 환골탈태 (2부 초반)

봉인이 터진 게 아니라 **금이 갔을 뿐**이다. 내공은 새어나오는데 완전히 열리지 않는다.
→ 힘은 과부하, 총량은 환골탈태 기준 미달. 죽지도 살지도 못하는 상태.

**해결은 기연이 아니라 기억.** 아버지가 걸었으니 아버지의 방식으로 풀어야 한다.
어릴 때 아버지가 시켰던 것 중 의미를 몰랐던 무언가를 진우가 기억해낸다.
※ 통신병 설정과 맞물림 — 봉인이 "잠긴 주파수"라면 신호로 이해하는 진우만 풀 수 있다.

## 판타지 세계 설계 (중요)

**기가 충만하다 = 진우가 더 세진다 (X)**
**기가 충만하다 = 기를 쓰는 존재가 흔하다 = 진우가 상대적으로 평범해진다 (O)**

절대치는 3배로 오르되 상대 순위는 내려간다. 중원 10위권 → 판타지 100위권.
3부에서 이기는 방식은 힘이 아니라 **조합** — 총 + 무공 + 현대 전술 + 통신.
